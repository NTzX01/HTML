เหตุผลที่อยากเรียน Full stack web development: เพื่อเพิ่มความรู้ความเข้าใจในการออกแบบ ทั้ง frontend และ backend เพื่อนำไปพัฒนาความสามารถทั้งเพื่อการทำงานและการเรียน

ความคาดหวังต่อวิชานี้: หวังว่าจะได้เรียนรู้เครื่องมือและกระบวนการทำงานจริง เข้าใจการเขียนโค้ดที่เป็นระบบ และสามารถนำความรู้ไปต่อยอดในการทำงาน

อะไรคือจุดอ่อนที่ตนเองต้องพัฒนาเกี่ยวกับทักษะ Programming และแนวทางการพัฒนา: จุดอ่อนคือทักษะการเขียนโปรแกรม ความหลากหลายของภาษาไม่เก่งภาษา แนวทางพัฒนา หาเวลาฝึกฝนให้เยอะทั้งการเขียนโปรแกรม และภาษา
